# Detection Engineering

This directory documents the detection rules
developed in the Home SOC Lab using Elastic Security.

## Detection Scenarios

- Multiple failed SMB network logons
- Encoded PowerShell command execution
- Suspicious scheduled task creation

## Detection Platform

- Elastic Security
- Windows Security Event Logs
- Sysmon
- Elastic Agent

Each detection will include its logic, severity,
MITRE ATT&CK mapping, testing procedure, and results.

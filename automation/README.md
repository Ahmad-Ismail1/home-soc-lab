# SOC Alert Automation

This directory contains Python automation scripts developed for the Home SOC Lab.

## Features

- Retrieve security alerts from Elastic Security.
- Export alert data to CSV files.
- Organize alerts by severity and investigation status.
- Generate a high-priority alert queue.

## Technologies

- Python 3
- Elasticsearch API
- Elastic Security
- CSV

## Main Script

`fetch_alerts.py` retrieves security alerts and prepares structured outputs for SOC investigation workflows.

## Security

API keys, credentials, and sensitive configuration files are excluded from the public repository.
